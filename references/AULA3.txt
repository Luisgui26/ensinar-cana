--- PÁGINA 2 ---
O que é o Counting Sort?

@ E um algoritmo de ordenacio por contagem: em vez de comparar
elementos entre si, ele conta quantas vezes cada valor aparece no
vetor.

@ Funciona quando os elementos sao inteiros dentro de um intervalo
conhecido [0, k].

@ Usa essas contagens para calcular diretamente a posicao final de
cada elemento no vetor ordenado.

Diferenca fundamental em relacao aos algoritmos anteriores

O Counting Sort nao divide o problema pela metade (como
MergeSort/QuickSort) nem decresce o problema em 1 (como
Selecéo/Bubble/Insertion). Ele simplesmente percorre os dados um
numero fixo de vezes. Por isso, nao existe uma formulacao recursiva
natural para esse algoritmo — ele é, por esséncia, iterativo.

Ideia geral do algoritmo de Fortaleza

O Counting Sort é feito em quatro fases:
@ Contar quantas vezes cada valor 0,1,...,k aparece em v;

@ Transformar essas contagens em somas acumuladas, obtendo
quantos elementos sao < cada valor;

@ Usar as somas acumuladas para colocar cada elemento de v
diretamente em sua posicao final em um vetor de saida;

@ Copiar o vetor de saida de volta para v (se necessario).

Cada fase é implementada com um laco simples, sem chamadas
recursivas.

@ MergeSort, QuickSort, Heap Sort: dividem o problema em partes
menores — recorréncia do tipo T(n) = a: T(n/b) + f(n);

@ Selecao, Bubble, Insertion Sort: decrescem 0 problema em 1 a cada

@ Counting Sort: ndo divide nem decresce 0 problema — ele percorre a

Sem chamadas recursivas, nao existe uma relacdo de recorréncia a

lacos — a mesma técnica usada para analisar as verses iterativas dos

--- PÁGINA 18 ---
Radix Sort e Bucket Sort (complemento)

Radix Sort

Generalizacaéo do Counting Sort: ordena os ntimeros digito a digito, do menos
significativo para o mais significativo, usando um algoritmo estavel (em geral o
proprio Counting Sort) em cada passagem. Complexidade O(d-n), onde d éo
numero de digitos.

[121, 432, 564, 23, 1, 45, 788] — unidade — dezena — centena

Bucket Sort

Distribui os n elementos, supostamente uniformemente distribuidos, em n
baldes; ordena cada balde e concatena os resultados. Caso médio @(n); pior caso
O(nlogn) (todos os elementos no mesmo balde).

Assim como o Counting Sort, ambos nao comparam elementos entre si — é por isso que
escapam do limite Q(nlogn).
